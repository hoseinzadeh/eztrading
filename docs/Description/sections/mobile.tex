\section{Mobile App Design}
\label{sec:mobile-app-design}

The mobile application for ezTrading is built to provide a simplified yet comprehensive trading and bot management experience. Although the mobile app lacks the Strategy Builder UI available in the web version, it compensates by offering a robust set of features tailored for on-the-go access.

\subsection{Authentication and Security}
\label{subsec:authentication-security}

Security is paramount in ezTrading's mobile app. Users can authenticate themselves using various biometric options like fingerprint scanning and face ID. Multi-factor authentication (MFA) is also available as an optional feature, requiring the user to confirm the login attempt from another trusted device using the ezTrading mobile app.

\subsection{User Interface}
\label{subsec:user-interface}

The user interface is intuitively designed, featuring a tabbed navigation bar at the bottom for easy access to different sections:

\begin{itemize}
    \item \textbf{Portfolio:} This tab provides a comprehensive review of the user's investment portfolio, including the real-time performance metrics of each trading bot and equity holding.
    
    \item \textbf{Watchlists:} Users can add bots or equities to their watchlists for quick access and monitoring.
    
    \item \textbf{Dashboard:} A centralized place for managing all active trading bots, viewing transaction history, and accessing other trading-related functionalities.
    
    \item \textbf{Marketplace:} Here, users can explore, search, and subscribe to new bots or trading strategies available on the platform.
    
    \item \textbf{Account:} This tab allows users to manage their account settings, payment options, and other personal preferences. Users can link multiple brokerage accounts (not available on certain plans).
\end{itemize}

\subsection{Portfolio Review}
\label{sec:portfolio-review}

The Portfolio Review tab provides a comprehensive overview of the user's current positions and holdings. It includes real-time data, asset allocation, and much more.


\paragraph{Linked Brokerage Accounts}
Users can choose between viewing the performance of individual linked brokerage accounts or an aggregated view that combines the performance of all linked accounts.

\paragraph{Charting}
The Portfolio Review tab includes a user-friendly charting feature that allows users to monitor their portfolio's performance over different time intervals, such as 1 day or 1 week. This functionality is detailed in Section~\ref{sec:charting}.

\paragraph{Related News}
Additionally, the Portfolio Review tab curates and lists news articles related to the securities in the user's portfolio, providing them with contextual information to make informed decisions.

\paragraph{Equity Search and Orders}
The Portfolio Review tab also features a search functionality for equities. Users can search for stocks, ETFs, and other securities, view their current market data, and place buy or sell orders right from within the app.

\paragraph{Stop-Loss and Limit Orders}
Users can set stop-loss orders to minimize potential losses and limit orders to execute trades at specific prices.

\paragraph{Trailing Stops}
The trailing stop feature allows the user to protect gains by setting an automatically-adjusting stop-loss order.

\paragraph{Option Trading}
Advanced traders can also manage options contracts, including buying calls and puts, and executing more complex strategies like iron condors or straddles.


\subsection{Bot Management}
\label{subsec:bot-management}

Within the Dashboard tab, users have the capability to pause, resume, or terminate their bots. Each bot is accompanied by essential statistics and graphs that reflect its performance, aiding users in making informed decisions.

By offering these features in a mobile-first design, ezTrading aims to make trading and bot management as straightforward and accessible as possible, ensuring that users can manage their investments wherever they are.
